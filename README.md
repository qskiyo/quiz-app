# 🧭 Interactive Quiz App

A dynamic, interactive quiz web application built to test user knowledge. This project was built during my dedicated web development preparation month ahead of my Software Engineering degree!

## 🛠️ Tech Stack Used
- **HTML5** & **CSS3** (Responsive UI/UX layout)
- **JavaScript (ES6+)** (Game logic, state handling, and score calculation)
- **React** (Component-based architecture)

## 🚀 Features
- Dynamic score tracking as you answer
- Instant visual feedback for correct/incorrect answers
- Fully responsive layout that looks great on mobile and desktop
